Terminal de validación de carnet

Un carnet, una ración, una vez al día. El semáforo le dice al alfabetizador qué entregar sin discutir.

I.E. Lola González Grado 10° PAE escolar

Terminal de validación

Escanea el carnet o escribe el código y presiona Validar. El semáforo responde en menos de dos segundos.

Formato LG-año-consecutivo. También funciona con el lector óptico USB o la cámara.

Prueba rápida

Escanea dos veces el mismo carnet para ver el bloqueo del doble reclamo.

Entregas de hoy

Cada fila es una ración entregada. La columna Hora es la que se usa para bloquear el segundo intento.

Qué revisa el algoritmo antes de entregar

1. ¿El carnet existe y está activo en el PAE?
2. ¿El estudiante ya reclamó hoy? Entonces se bloquea.
3. ¿Qué modalidad le corresponde? Vaso de leche o plato verde.
